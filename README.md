# Podcast Brand Logo Generator 🎙️

A youthful and unique podcast logo generator that creates vibrant, modern logos in JPEG format perfect for videos and branding.

## Features

- 🎨 Modern gradient background (purple → pink → orange)
- 🎙️ Stylized podcast microphone icon
- 💫 Dynamic sound wave effects
- 📱 High-quality JPEG output
- 🎯 Two size options: Standard (1000x1000) and HD (2000x2000)

## Quick Start

### Installation

```bash
pip install -r requirements.txt
```

### Generate Your Logo

```bash
python generate_logo.py
```

This will create:
- `podcast_logo.jpg` (1000x1000) - Perfect for videos and social media
- `podcast_logo_hd.jpg` (2000x2000) - High resolution for printing

## Usage

The logo is automatically generated when you run the script. You can also use it as a module:

```python
from generate_logo import create_podcast_logo

# Create a custom size logo
create_podcast_logo('my_logo.jpg', size=1500)
```

## Design Details

The logo features:
- **Vibrant gradient background**: Creates a youthful, energetic feel
- **Podcast microphone**: Central iconic element representing audio content
- **Sound waves**: Dynamic elements showing audio in motion
- **Professional styling**: Clean, modern design suitable for all platforms
