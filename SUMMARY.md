## 🚀 How to Use Your Logo

### Quick Download
Both logo files are in the repository root:
- `podcast_logo.jpg` - Standard version for digital use
- `podcast_logo_hd.jpg` - HD version for printing

### Add to Your Videos
1. Download `podcast_logo.jpg`
2. Import into your video editor (iMovie, Premiere, Final Cut, etc.)
3. Add as a corner watermark, intro screen, or thumbnail
4. Export and upload!

### Regenerate or Customize
If you want to create a custom size:
```bash
pip install -r requirements.txt
python generate_logo.py
```

Or programmatically:
```python
from generate_logo import create_podcast_logo
create_podcast_logo('my_custom_logo.jpg', size=1500)
```
