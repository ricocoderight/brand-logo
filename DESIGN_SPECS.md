# Podcast Logo Design Specifications

## Overview
Youthful and unique podcast logo designed for modern content creators.

## Visual Design

### Color Palette
- **Primary Gradient**: Purple (#8A2BE2) → Pink (#FF69B4) → Orange (#FFA500)
- **Microphone Color**: Vibrant Purple (#5818C7)
- **Sound Waves**: Hot Pink (#FF458F)
- **Text Color**: Deep Purple (#5818C7)
- **Background Circle**: White with slight transparency

### Typography
- Font: DejaVu Sans Bold (or system default)
- Text: "PODCAST"
- Size: 12% of logo height
- Position: Bottom center of circular frame

### Icon Elements
1. **Microphone**
   - Rounded capsule shape
   - Size: 12% width × 18% height
   - Position: Upper center
   - Style: Solid fill with rounded edges

2. **Sound Waves**
   - 3 curved lines on each side
   - Progressively larger from mic outward
   - Creates sense of audio broadcasting
   - Animated-style appearance

3. **Circular Frame**
   - White circle with thick border
   - Outer radius: 45% of image
   - Inner radius: 38% of image
   - Creates professional focal point

## File Specifications

### Standard Version (podcast_logo.jpg)
- **Dimensions**: 1000 × 1000 pixels
- **Format**: JPEG
- **Quality**: 95%
- **File Size**: ~83KB
- **Use Case**: Digital media, videos, social media

### HD Version (podcast_logo_hd.jpg)
- **Dimensions**: 2000 × 2000 pixels
- **Format**: JPEG
- **Quality**: 95%
- **File Size**: ~187KB
- **Use Case**: Printing, large displays, scalable branding

## Usage Guidelines

### Recommended Sizes
- YouTube Thumbnail: 1000x1000 (standard version)
- Instagram Post: 1000x1000 (standard version)
- Profile Picture: 1000x1000 (standard version)
- Print Materials: 2000x2000 (HD version)
- Website Header: Either version works

### Do's
✓ Use on video thumbnails and intros
✓ Display on podcast platforms
✓ Include in social media posts
✓ Add to merchandise designs
✓ Scale proportionally

### Don'ts
✗ Stretch or distort the logo
✗ Change the color scheme
✗ Add filters that obscure the design
✗ Place on busy backgrounds without spacing
✗ Crop out key elements

## Technical Details

### Generation Method
- Programmatically generated using Python and Pillow (PIL)
- Reproducible and customizable
- No external image dependencies
- Vector-style rendering to raster

### Compatibility
- Compatible with all major video editors
- Works in social media platforms
- Suitable for web and print
- Optimized JPEG compression

### Customization
The logo can be regenerated with custom dimensions:
```python
create_podcast_logo('custom_logo.jpg', size=1500)
```
